# Obrigado ES — graciassophi.vercel.app

Projeto **só** da página de obrigado (espanhol). Sem API Opeera aqui.

## Deploy
1. Repo com o conteúdo desta pasta `obrigado-es/`
2. Vercel → Framework Other → domínio `graciassophi.vercel.app`
3. Sem env obrigatória (pixel está no HTML)

## Pixel Meta
ID `1339532338381439`
- `PageView`
- `Purchase` com `value` + `currency=USD` (lê `?amount=` da URL)

Na landing (`opeera-es`), o `THANK_YOU_URL` deve ser `https://graciassophi.vercel.app`.
